# Neorest playgrounds

These are runnable browser examples. Start with the smallest one and move to
the next only when you need real-time updates.

| Example | What it demonstrates |
| --- | --- |
| [`simplest`](simplest) | connect and call one route |
| [`chat`](chat) | load state, subscribe, and post changes |

Each example has its own setup instructions. For smaller copy-paste recipes,
see [Simple examples](../../docs/examples.md).
